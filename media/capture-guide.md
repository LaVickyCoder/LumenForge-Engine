# Public Capture Guide

Use screenshots that show a real LumenForge build and keep the frame focused on the engine output.

## Capture 1 — Native window

Recommended:

- run the WindowLifecycle sample/build;
- show the LumenForge window clearly;
- crop to the application and only enough desktop context to look natural;
- PNG preferred;
- suggested name: `screenshots/native-window.png`.

## Capture 2 — D3D12 bootstrap

If the current executable or log output shows adapter/device information in a useful way:

- capture only the relevant output;
- keep the frame clean and readable;
- suggested name: `screenshots/d3d12-bootstrap.png`.

## Future capture — first presented frame

Only add this once swapchain/presentation is integrated into the verified baseline.

## Recommended dimensions

For README hero screenshots, 1600×900 or 1920×1080 works well. Avoid aggressive compression and tiny terminal text.
