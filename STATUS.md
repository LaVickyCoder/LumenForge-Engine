# Project Status

## Current state

LumenForge Engine is in **pre-alpha active development**.

The current private source history has reached the integrated milestone:

**E1-M02 — Concrete D3D12 Bootstrap**

The engine is still establishing low-level contracts and platform foundations. It is not yet suitable for production game development.

## Foundations already represented in the engine

- Core utility and type layer
- Diagnostics contracts
- Windows platform layer
- High-resolution time services
- Filesystem layer
- Window lifecycle
- Input event/state handling
- Binary serialization foundations
- Backend-neutral Render Hardware Interface contracts
- Direct3D 12 bootstrap

## What “pre-alpha” means here

APIs may change without compatibility guarantees. Systems may be replaced or restructured as architecture is validated. Public binaries, SDK guarantees, editor workflows, asset compatibility, and commercial support commitments do not exist yet.

This file will be updated as externally meaningful milestones are reached.
