# Contributing

Thank you for your interest in LumenForge Engine.

During the current pre-alpha stage, the complete engine source and internal development process remain private. This public repository is primarily intended for project communication, documentation, roadmap visibility, demos, and future public components.

## Currently welcome

- Documentation corrections
- Reproducible reports concerning public demos or public SDK/runtime material
- Compatibility observations
- Constructive architecture/documentation feedback

## Not currently accepted

Unsolicited source-code contributions to the proprietary engine core are not currently accepted through this public surface.

Contribution rules may expand when externally licensed or community-facing components are released.
