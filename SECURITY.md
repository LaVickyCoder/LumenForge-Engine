# Security Policy

LumenForge is currently pre-alpha and does not yet publish a supported production runtime.

If you believe you have found a security issue in publicly released LumenForge material, please avoid posting exploit details, credentials, or other sensitive information in a public issue.

Until a dedicated private reporting channel is published, open a minimal GitHub issue requesting a private security contact without including sensitive technical details.

Security support commitments and version-support windows will be defined before production releases.
