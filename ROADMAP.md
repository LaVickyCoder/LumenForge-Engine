# LumenForge Roadmap

This roadmap describes direction rather than fixed delivery dates. Priorities may change as architecture is validated.

## Phase 1 — Native foundation

**Status: active / substantially underway**

- Core types and utility contracts
- Diagnostics
- Platform abstraction
- Time
- Filesystem
- Window lifecycle
- Input
- Serialization

## Phase 2 — Rendering foundation

**Status: active**

- Backend-neutral RHI contracts
- Direct3D 12 bootstrap
- Adapter/device selection and failure handling
- Resource and synchronization foundations
- Shader and pipeline management
- Frame execution architecture

## Phase 3 — Runtime systems

**Planned direction**

- Scene/world representation
- Entity/component architecture
- Asset runtime
- Resource streaming
- Animation foundations
- Audio foundations
- Physics integration
- Gameplay-facing runtime APIs

## Phase 4 — Tools and content pipeline

**Planned direction**

- Asset import and cooking
- Editor foundations
- Scene/content authoring
- Profiling and diagnostics tools
- Build/package workflows

## Phase 5 — Production capability

**Long-term direction**

- Scalable rendering features
- Performance and memory tooling
- Large-content workflows
- Networking foundations
- Team/studio workflows
- Stable SDK/runtime interfaces
- External developer documentation

## External availability

Public demos and selected externally usable components may appear before the full engine is commercially available. No release date or pricing commitment is being made at this stage.
