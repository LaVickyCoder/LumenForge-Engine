# Native Window Lifecycle

**Integrated:** 2026-09-19  
**Status:** ✅ Verified integrated capability

The Window subsystem established the first native interactive runtime surface.

## Current scope

- create/show/close/destroy lifecycle;
- event pumping;
- open/close state;
- client-size query;
- resize consumption;
- Windows implementation and lifecycle regression tests.

This is an engine subsystem milestone, not yet an editor or rendering viewport.
