# Versioned Binary Serialization Foundation

**Integrated:** 2026-09-19  
**Status:** ✅ Verified integrated capability

The serialization foundation introduced versioned binary-reference encoding/decoding and migration contracts.

## Current scope

- versioned reference representation;
- encode/decode contract;
- serialization-specific errors;
- migration foundation;
- tests for valid and invalid inputs.

## Not claimed

This is not yet a complete scene format, asset database, save-game system or final public file format.
